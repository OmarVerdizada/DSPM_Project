# Runtime dependencies only. Development and test tooling lives in
# requirements-dev.txt; optional ML classification extras live in
# requirements-ml.txt.
#
# Requires Python 3.12 or newer (tested to 3.14). The floor moved from 3.10 to
# 3.12 on 2026-09-21 (roadmap M0/Q3): 3.10 leaves upstream support in October
# 2026, and the lock must be generated on the floor, so the floor has to be a
# version this project actually builds and tests on.
#
# Direct dependencies are pinned exactly here. For a fully reproducible,
# hash-verified install of the entire transitive tree, use the generated lock:
#     pip install --require-hashes -r requirements.lock
# Regenerate it after changing this file:
#     pip-compile --generate-hashes --output-file=requirements.lock requirements.txt
# Generate it on the FLOOR interpreter (3.12): the drift gate in CI regenerates
# it there and compares pins and hashes.
# (CI verifies requirements.lock stays in sync and builds the SBOM from it.)
