# Frontend refit baseline — 2026-09-02

The "before" state, captured at the start of phase F0 so every later phase can
be measured rather than argued about. Numbers come from the running product at
1366×768 (checks at 1280×720 and 1024×768), default tenant with real scan data,
light and dark.

**Captured from the working tree, which contained in-flight feature work**
(admin-only nav gating, scan-kind source groups, tenant dashboard guards). The
assessment recommended waiting for that to merge; F0 proceeded on request, so
this baseline includes it. That is the honest starting line for F3.

Regenerate the debt counters at any time with:

```bash
python scripts/check_frontend_tokens.py --stats
```

## Stylesheet debt

Measured on `frontend/styles.css` **after** F0 removed 78 provably-dead token
declarations (5 fully-overridden `:root` blocks, 92 lines).

| Counter | F0 baseline | F5 target |
| --- | ---: | ---: |
| `styles.css` lines | 23,949 | ≤ 8,000 |
| `!important` | 3,877 | < 300 |
| `:root:root` specificity hammers | 352 | 0 |
| Distinct `font-size` values | 41 | 6 |
| Distinct `border-radius` values | 21 | 3 |
| `box-shadow` declarations | 378 | 2 |
| `text-transform: uppercase` rules | 83 | 1 (`.eyebrow`) |
| Raw hex colours | 794 | 0 outside `tokens.css` |

The `!important` and hex counts are higher than the assessment's figures (3,760
and 246) because the assessment counted `styles.css` before the in-flight work
landed, and because the hex count here includes every occurrence rather than
distinct values. The gate freezes both from here.

## Visual baseline

Screenshots captured during F0 at 1366×768: Dashboard (light and dark), Scan →
File server, Evidence → Reports, Administration → Security ops, Evidence →
History, the scan wizard step 1, and the asset detail modal. They live in the
session transcript rather than the repository — binary screenshots in git would
bloat the on-prem delivery package for no operational benefit. F3 re-captures
per page and compares against the numbers in this file, which are the part that
can actually be diffed.

## How F6 uses this

publish the before/after. A phase is done when its target column is met, not
when it looks finished.
